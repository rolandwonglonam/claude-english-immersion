## Writing — Essay (Write Essay)

### 评分权重（2025-08-07 更新后）

| 维度 | 旧权重 | 新权重 |
| :--- | :---: | :---: |
| Content | 2 | **6** |
| Coherence, Structure & Development | 2 | **6** |
| General Linguistic Range | 2 | **6** |
| Grammar | 2 | 2 |
| Spelling | 2 | 2 |
| Form | 2 | 2 |
| **总分** | 12 | **24** |

Essay 现在占 writing section **26-30 分**。AI 评分更智能，模板式 generic answers 不再给高分。

### 硬规则

| # | 规则 |
| :---: | :--- |
| 1 | **字数 250-270**（不是旧的 200-300；content 权重上升，字数要稍高；上限不超 300） |
| 2 | **四段结构**：Intro / Body 1 / Body 2 / Conclusion |
| 3 | **每个 body 段落 1 个 main idea 就够**，不要塞 5 个 10 个 |
| 4 | **每个 main idea 必须有 supporting point + example**（CWES: Claim-Why-Example-So what） |
| 5 | **Spelling 错误上限 2 个**（错 1 扣 1，错 2 扣 2，错 ≥2 直接 0） |
| 6 | **句型必须混合**：simple + compound(and/but) + complex(because/although) + relative clause(which/who) |
| 7 | **Advantage-outweigh-disadvantage 不看 "outnumber" 看 "outweigh"**——1 个强 advantage 可以压 5 个弱 disadvantage，不用 1:1 堆数量 |
| 8 | **讨论坏面段结尾必须加 proactive measures 句**（告诉 AI 你知道有缓解方案，提高 coherence 分） |

### 三步解题法

1. **Decide structure**: 读题，判断题型（advantage vs disadvantage / agree-disagree / discuss both / problem-solution），选模板
2. **Ideation**: brain dump → 用 **PPP filter** 挑 idea：
   - **Powerful**（有力）
   - **Provable**（能证明）
   - **Personalizable**（能用个人经验佐证）
3. **Implementation**: 用选定的结构模板把 CWES 骨架填进去

### Advantage-outweigh-Disadvantage 四段模板（骨架）

```
[Para 1 — Intro]
In today's society, {topic} has become increasingly common as ...
While some people believe that {advantages}, others argue {disadvantages}.
My view is that the benefits of {topic} outweigh the drawbacks.
This essay will explore the various advantages of {topic} and demonstrate
why they hold greater significance compared to the disadvantages.

[Para 2 — Body 1: advantages]
To begin with, one prominent advantage of {topic} is {claim1}.
This means {why1}.
For instance, {example1}.
Moreover, another advantage is that {topic} {claim2}.
This refers to the fact that {why2}.
(可选：再写 example2 如果字数允许)

[Para 3 — Body 2: disadvantages]
Despite its advantages, {topic} also presents several disadvantages.
One notable drawback is {claim3}.
This is due to the fact that {why3}.
For instance, {example3}.
These disadvantages highlight the need for proactive measures
to ensure {缓和说明}.

[Para 4 — Conclusion]
In conclusion, while {topic} has disadvantages such as {回顾 claim3},
the advantages it offers are undeniable.
Therefore, it is evident that the advantages of {topic} outweigh
the disadvantages, reinforcing its importance in modern society.
```

**这不是必须背的模板**——是骨架。你如果有自己的结构可以用，但每个位置的**功能**（paraphrase、stance、signpost、CWES、proactive closer、restate）不能少。

### Linguistic range 示例（考前默背一下每种句型）

| 句型 | 示例 |
| :--- | :--- |
| Simple | `I like coffee.` |
| Compound (and/but/or) | `I like coffee and I also enjoy tea.` |
| Complex (because/although/while/since) | `I drink coffee because it keeps me awake during long study sessions.` |
| Relative clause (which/who/where/when/that) | `Coffee, which many students rely on, can be addictive.` |

## Writing — Summarize Written Text (SWT)

### 评分权重（2025-08-07 更新后）

| 维度 | 旧权重 | 新权重 |
| :--- | :---: | :---: |
| Content | 2 | **4** |
| Form | 1 | 1 |
| Grammar | 2 | 2 |
| Vocabulary | 2 | 2 |
| Spelling | （并入 grammar） | — |
| **总分** | 9 | **9** |

SWT 从 2 道题约占 **19-20 分 → writing** 和 **19-20 分 → reading**，两边都贡献，是冲 writing 85 / reading 70 的关键模块。

### 硬规则

| # | 规则 |
| :---: | :--- |
| 1 | **字数 55-70**（PTE Academic） / **25-50**（PTE Core） |
| 2 | **必须单句**：整句只能有 1 个句号（分号可以，逗号可以） |
| 3 | **必须以句号结尾**（漏句号 → writing & reading 直接 0 分） |
| 4 | **分号后小写**（分号是句内续写不是新句） |
| 5 | **Content 4/4 要求**：从段落**不同部分**取内容（头 + 中 + 尾），不要全从开头 |
| 6 | **Copy-paste 方法仍有效**（非对话段），但考试界面的 copy button 大概率不工作 → 手打 |
| 7 | **不取问号句** |
| 8 | **不切半句**——从句号到句号完整取 |
| 9 | **括号内容保留**（原样抄） |
| 10 | **对话类段落必须 paraphrase**（copy paste 逻辑不通） |

### 7 个推荐模板（按推荐度排序）

| 推荐度 | 模板 | 适用 |
| :---: | :--- | :--- |
| ★★★ | `While S1, S2; S3.` | **首选**，让步+分号，体现 linguistic range |
| ★★★ | `While S1, S2; S3, and S4.` | 段落含 4 个关键句时 |
| ★★★ | `Although S1, S2, and S3.` | 让步开头，三分支收尾 |
| ★★★ | `S1, and S2, but S3.` | 三分支协调，需要分散覆盖头/中/尾 |
| ★★ | `Although S1, S2.` | 保守，双句足够时 |
| ★ | `S1, and S2.` | 最简，容易 content 不够（只有 2 句时 AI 判覆盖不全） |
| ★ | `S1, but S2.` | 同上问题 |

**规则**：优先选 **3 句版模板**（★★★ 那四个），因为 content 升到 4/4 需要覆盖段落三个区域。

### 对话类 SWT Paraphrase 模板

```
While {speaker1_name} explains {speaker1_content},
{speaker2_name} says/acknowledges/retorts {speaker2_content};
both agree/disagree/acknowledge {common_point}.
```

- `both` 的 `b` 必须**小写**（因为前面是分号）
- 约 55-60 字
- 用 `while / says / agrees / acknowledges / disagrees / retorts` 这些动词切分说话人
- 不写 "Speaker 1 / Speaker 2"，写具体人名

### Paraphrase 四原则（对话类专用）

1. **同意思换词**：不改变原意
2. **同义词替换**：revolutionized → transformed；communicate → interact
3. **改结构**：`He eats the pizza.` → `The pizza is eaten by him.`
4. **避免长句原样抄**：只能留 2-3 个原词，其他改写

## 考前一晚 checklist（5 分钟版）

- [ ] Essay：250-270 字、四段、CWES 骨架、proactive closer、混句型
- [ ] Essay：intro 改写 + 表态 + "This essay will explore..."
- [ ] Essay：conclusion "In conclusion, while ... the advantages it offers are undeniable."
- [ ] SWT：55-70 字、单句、句号收尾、分号后小写
- [ ] SWT：首选 `While S1, S2; S3.` 或 `While S1, S2; S3, and S4.`
- [ ] SWT：对话题用 `While A ..., B ...; both agree ...`
- [ ] SWT：从段落头/中/尾三处取内容
- [ ] Spelling：别超过 2 个错（essay），SWT 别错（并入 grammar）
- [ ] 两题都看清楚题目 topic，别写偏
