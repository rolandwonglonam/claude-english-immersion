# PTE Rubrics Reference

Condensed rubrics for the four PTE Academic tasks this skill supports. Based on Pearson's published scoring guides. Use these to grade Roland's practice output in the sub-skills.

**General note**: PTE uses automated scoring in the real exam. Claude's scoring is a human approximation — it correlates with, but is not identical to, the official algorithm. Treat scores as directional, not exact.

---

## Write Essay

**Prompt format**: An argumentative topic, 200-300 word response in 20 minutes.

**Scoring dimensions** (each 0-3 unless noted):

| Dimension | Max | What to check |
| :--- | :---: | :--- |
| Content | 3 | Does the essay address the prompt? Does it take a clear position and support it? 0 = off-topic. |
| Form | 2 | Word count 200-300. Below 200 or above 300 caps at 0. |
| Development, structure, coherence | 2 | Intro / body / conclusion. Logical progression. Transitions. |
| Grammar | 2 | Sentence-level correctness. Minor errors OK at 1; major errors at 0. |
| General linguistic range | 2 | Sentence variety, complex structures, not all simple subject-verb-object |
| Vocabulary range | 2 | Precise word choice, appropriate register, not repetitive |
| Spelling | 1 | 0 errors = 1; any error = 0 |

**Total**: 15 points, scaled to PTE Writing contribution.

**How to grade in the sub-skill**:
1. Read the essay
2. For each dimension, assign a score and state the concrete evidence
3. Report total + dimension breakdown + the ONE dimension that would give the biggest score improvement next time

## Summarize Written Text (SWT)

**Prompt format**: A 300-word passage. Response must be **one single sentence** of 5-75 words summarizing the main idea.

**Scoring dimensions**:

| Dimension | Max | What to check |
| :--- | :---: | :--- |
| Content | 2 | Captures the main idea and no off-topic content |
| Form | 1 | Exactly one sentence, 5-75 words. Two sentences = 0. |
| Grammar | 2 | Grammatical correctness of that one sentence |
| Vocabulary | 2 | Appropriate words, correct spelling |

**Total**: 7 points.

**Critical trap**: Multiple sentences = instant 0 on Form. No matter how good the content is, the whole task caps at 0 if form fails. **Warn Roland in every SWT grading.**

**Good technique for the single-sentence constraint**:
- Use semicolons, commas with conjunctions, and subordinate clauses to chain ideas
- Lead with the main claim, then attach modifiers
- Avoid starting with the author's name or the passage title

## Describe Image

**Prompt format**: An image (chart, graph, map, photo). Roland has 25 seconds to study it, then speaks for **40 seconds** describing it.

**Scoring dimensions**:

| Dimension | Max | What to check |
| :--- | :---: | :--- |
| Content | 5 | Covers all key features of the image. For charts: title, axes, trends, max/min, conclusion. |
| Oral fluency | 5 | Smooth speech, no long pauses, consistent pace. (Roland self-reports) |
| Pronunciation | 5 | Native-like articulation. (Roland self-reports) |

**How this sub-skill grades**:

1. Roland describes the image in text (pasting what he would say, or actually recording himself and transcribing)
2. Claude scores **Content** from the transcript
3. For **Oral fluency** and **Pronunciation**, Claude asks Roland to self-rate 1-5 honestly (did you pause? did you hesitate? did you feel fluent?) and records the self-rating
4. Output: content score + self-rated fluency + self-rated pronunciation + the ONE structural element he missed (e.g., "you didn't state the conclusion the graph supports")

**Standard describe-image template** (drill this into Roland):

1. **What it is** (one sentence): "This is a bar chart showing X over Y."
2. **Key feature 1** (highest / most notable): "The highest value is X at Y."
3. **Key feature 2** (contrast / lowest / trend): "In contrast, Z is the lowest at W."
4. **Overall pattern**: "Overall, the data suggests..."

40 seconds is tight. Four sentences, pre-chunked, is the safe structure.

## Read Aloud

**Prompt format**: A 60-word passage on screen. 30-40 seconds preparation, then read aloud in 35-40 seconds.

**Scoring dimensions**:

| Dimension | Max | What to check |
| :--- | :---: | :--- |
| Content | 5 | Read every word, in order, no substitutions |
| Oral fluency | 5 | Smooth continuous speech, natural phrasing |
| Pronunciation | 5 | Each word recognizable as standard English |

**How this sub-skill grades**:

1. Claude provides a difficulty-calibrated 60-word passage
2. Roland reads it aloud (ideally recording himself)
3. Roland self-reports: "Any word I tripped on? Any sentence I restarted? How fluent did it feel (1-5)?"
4. Claude flags high-risk words in the passage (long syllable counts, unusual stress patterns, Latinate roots) and asks Roland to confirm each one sounded correct
5. Output: self-rated scores + flagged words to drill individually

**Difficulty progression**:
- **Week 1-2**: Concrete topics, common vocabulary, short sentences
- **Week 3-4**: Abstract topics (economics, science), mixed vocabulary, compound sentences
- **Week 5+**: Academic register, Latinate vocabulary, complex sentence structures matching real PTE passages

Real PTE Read Aloud passages come from academic journals. The final weeks should mirror that register.

## Scoring band mapping (approximate)

PTE reports scores 10-90 per skill. Rough bands:

| Band | Overall | What it means |
| :--- | :--- | :--- |
| 30-49 | Below functional | Beginner |
| 50-57 | Functional | Can handle daily communication |
| 58-64 | Competent | Can handle most workplace contexts |
| **65-78** | **Proficient** | **Roland's target zone** |
| 79-90 | Expert | Near-native |

65 in all four sections requires: Writing rubric totals around 10-11 / 15 per task, SWT around 5-6 / 7 per task, Describe Image around 12-13 / 15 with good self-ratings, Read Aloud around 13-14 / 15 with good self-ratings.

These are internal approximations — use them to set weekly targets, not to promise exam scores.
